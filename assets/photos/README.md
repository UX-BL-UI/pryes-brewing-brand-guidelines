# Concept Board photos

Real photos the Concept Board can drop into poster concepts (can renders, taproom shots, beer glamour shots).

**To add a photo:**
1. Drop the image file (JPG, PNG, or WebP) into this folder.
2. Add one line for it inside `photos.json`, for example: `{ "file": "miraculum-can.jpg", "label": "Miraculum can" }`

That's it. The board picks it up on the next page load.

**Only real photography belongs here** - can renders, taproom shots, lifestyle photos. No screenshots, no guideline pages, no placeholders. (`sample-photo.png` in this folder is unused for that reason; ask Ben before adding it back to `photos.json`.)
