# Pryes Brewing — Brand Guide 2026

A self-contained mini-site for the refreshed Pryes Brewing brand. It presents the
2026 brand guide (foundation, logo, color, typography, photography, patterns and
applications) and doubles as a self-serve library for the working asset files.

## View it

Open [`pryes-brand-guidelines.html`](pryes-brand-guidelines.html) in any browser —
no build step, no dependencies. Everything is one HTML file plus the `assets/`
folder.

The site is password protected (client-side). Default password: **`pryes2026`** —
change it in the `CORRECT_PASSWORD` constant near the bottom of the HTML.

## What's inside

The page mirrors the 55-page brand guide and is faithful to the finalized brand:

- **Palette** — Regal Burgundy, Beer Foam, Beige, Miraculum Green and the
  off-blacks, plus packaging accents. Click any swatch to copy its HEX.
- **Type** — the guide's sanctioned web stack (Source Serif 4 · Poppins · Barlow
  Condensed) standing in for the licensed print faces (Superclarendon · Gotham ·
  Alternate Gothic), so the site renders as specified without licensing conflicts.
- **Logo, patterns, shapes and documents** — shown inline and downloadable.

## Asset library (`assets/`)

| Folder | Contents |
| --- | --- |
| `assets/logos/` | Full logo suite — SVG + PNG, in every colorway (Beer Foam, Burgundy, Burgundy Off-Black, White, Black) |
| `assets/patterns/` | Laurel and logo patterns — SVG + PNG, all colorways |
| `assets/shapes/` | Container / border shapes — SVG, all colorways |
| `assets/documents/` | Master **Brand Guide 2026** PDF, plus Shelf Talkers and Shapes PDFs |
| `assets/previews/` | Rendered application examples used on the Applications page |

The complete source suite (including EPS and the large print-production files such
as cooler clings and posters) lives in the shared
`PRYES/2026/PRYES-BRAND-ASSETS` folder.
